What this model does

Oncology specs fail in predictable places: RECIST arithmetic, response confirmation, PFS censoring after missed scans or new therapy, and data elements that drift from their CDISC definitions. Each of those is code here, tested on load, and tied to a Biomedical Concept from the CDISC library.

CapabilityUSDM 4This modelTry it
The posted protocol is readable but the SAP section is not, so oncology conventions the SAP would normally fix (the two-missed-scans rule, the confirmation window, the minimum SD duration) are modelled as explicit parameters and flagged in Spec checks rather than presented as the sponsor's rules.

Study design

Randomized, open-label, active-controlled phase 3. Because investigators know the arm, the primary endpoint is PFS by blinded independent central review (BICR).

Computable estimands

Each estimand links forward to its Biomedical Concepts, derivation rules (tested live) and output. Oncology adds what cardiology didn't need: response confirmation, scan schedules and a hypothetical strategy for new anticancer therapy.

Testing and alpha

PFS by BICR is tested first. Only if it is significant does OS get tested, across three looks with Lan–DeMets O'Brien–Fleming spending. The boundaries are computed in the page by recursive numerical integration, so a DMC or programmer can see in advance exactly what result would cross at each look.

Information fractions from Protocol §11.5 (≈96, 153, 250 deaths). At a real look the boundary is recomputed from the actual number of deaths; change the fractions to rehearse that.

Dry run on mock data

Before any real data exist, this simulates patients down to individual scans: tumor sums at every 6-week visit with window jitter and missed scans, new lesions, new anticancer therapy and deaths. Each scan becomes BC-conformant SDTM (TR, RS), the RECIST engine derives responses, the PFS rule cuts the data at the 335th BICR event, and a Cox model stratified by the 8 randomization strata gives the hazard ratio.
